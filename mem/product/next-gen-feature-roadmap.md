# Next-Gen Feature Roadmap

> Three lanes: **Cut** (subtract), **Sharpen** (existing → 10×), **Invent**
> (net-new bets). Sized by leverage, not effort.

---

## Lane A — CUT (week 1, ruthless)

| Cut | Replaced by |
|-----|-------------|
| Marketing1/2, HowItWorks, Platform | single `/` landing |
| WorkspaceGateway/Landing/Portal/Workspaces | single `/workspace` |
| SavedHustles, SavedGuides | `/library` |
| Standalone tool pages (RedFlagScanner, SkillGap, GigArbitrage…) | `/tools` grid |
| 30+ admin panels | `/admin/operations` sections |
| Phase/migration vocabulary in UI | production vocabulary |
| Status, Health, AuthDebug from public | admin-only |

**Outcome:** 91 routes → ~35. The product becomes legible.

---

## Lane B — SHARPEN (weeks 2–6)

### B1. The Cockpit (replaces /dashboard)
Morning Brief · Active Canvas · Agent Activity · Money Meter · Streak.  
Leverage: defines the daily habit. **Highest activation lift.**

### B2. Canvas Smart Blocks
`/brief` `/proposal` `/pricing` `/contract` `/lead` `/agent`.  
Each is an AI-native action, not text.  
Leverage: turns canvas from a doc into an OS.

### B3. Workspace Memory layer
`workspace_memory` table + nightly summariser + injection into every call.  
Leverage: every AI call feels personalised for free.

### B4. Agent Plans
Visible, editable plan before any multi-step run.  
Leverage: trust + control + reduces "AI runaway" anxiety.

### B5. Command Palette (`⌘K`)
One shortcut, every action.  
Leverage: power-user delight + retention signal.

### B6. BYOK Cost Lens
Live per-provider cost + "you saved ₹X this month".  
Leverage: justifies BYOK friction with visible ROI.

### B7. Predictive Operations
AI predicts outages 6h ahead; auto-engages Incident Mode at 3+ trips/60s.  
Leverage: operator confidence; sales narrative.

### B8. Weekly Wins email
AI-generated recap delivered Fridays.  
Leverage: dormant-user reactivation; viral surface.

## Lane C — INVENT (weeks 7–12)

### C1. Multiplayer Canvas (Agency tier)
Realtime cursors, comments, AI-summarised review threads.  
Pricing unlock: **seat-based Agency plan.**

### C2. Agent Marketplace
Creators publish agents; 70/30 split; weekly featured drops.  
New revenue line; community flywheel.

### C3. Templates Marketplace
Same model for canvas templates.  
Compounds with C2.

### C4. Public Workspaces (opt-in)
Shareable read-only canvases → SEO + acquisition loop.  
Pattern: Notion + Read.cv + Linear roadmap.

### C5. Outcome Pricing
Pay per won gig, not per token. Bold bet, narrow pilot first.

### C6. HustleOS Mobile
Voice-first daily brief + capture. Web stays for execution.

### C7. AI Confidence + Explainability layer
Every output ships with 1–5 confidence + "show me how you decided".

### C8. Async Voice Notes → Actions
Voice in → transcript → suggested actions → executed agents.  
Killer mobile feature.

## "This changes the product completely" bets

1. **Cockpit as the homepage of the app.** Not a dashboard, a control tower.
2. **Smart Blocks turn the canvas into an execution OS.**
3. **Agent Marketplace** flips HustleAI from product to platform.
4. **Outcome Pricing** redefines AI SaaS pricing in the freelancer niche.
5. **Voice-first mobile** captures the daily moment desktop SaaS misses.

## Success metrics (what we are actually optimising)

- **Activation:** % of signups that complete first canvas in < 5 min.
- **D1/D7/D30 retention.**
- **Daily Brief open rate.**
- **Median time-to-first-AI-action** (target < 60s).
- **Power-user signal:** % users using `⌘K` weekly.
- **Revenue per active workspace** (not per user).
- **NPS — "Would you tell another freelancer about this?"**

---

## The new shipping rule (companion to 9.4)

No new feature ships unless ALL apply:
- it earns a place in the cockpit, canvas, or agent runtime,
- it reduces — not adds — surface area,
- it has an AI-native version of itself (not a UI for a thing),
- it makes the product feel calmer, not busier,
- it produces *visible execution power* the user can feel in 30 seconds.

**HustleAI is no longer building features.  
It is becoming the operating system for intelligent execution.**
