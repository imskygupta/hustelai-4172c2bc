# AI Runtime Experience (UX Contract)

Infra is stable (`mem/runtime/runtime-stability-verification.md`).
This memo defines the *experience* contract for every AI surface.
NO new infra. NO new telemetry. NO new tables.

## Core principle

> The AI should feel **fast, trustworthy, and continuous** — even when it isn't.

If we can't make it faster, we make it *feel* faster. If we can't guarantee
success, we make failure *recoverable*. If we can't remember everything,
we make the visible context *feel like memory*.

## 1. Perceived speed

| Call duration | UX treatment |
|---|---|
| <800ms | Instant — no skeleton, just result |
| 800ms–3s | Shimmer skeleton with the user's prompt echoed at top |
| 3s–8s | Streamed tokens (real or simulated chunking); progress feels alive |
| 8s+ | Background pill in header: "Drafting proposal… (view)". User can navigate away. |
| 8s deadline hit | Friendly: "Taking longer than usual. Keep waiting or try again with a smaller scope." NEVER a raw error. |

Rules:
- Skeletons NEVER static. Always shimmer or progressive.
- Loading copy rotates motivational tips (existing pattern). No bare "Loading…".
- Single canonical skeleton component — no per-surface variants.

## 2. Trust & confidence presentation

Every AI output must show:
- **Model attribution**: `Generated by Gemini 2.5 Pro · 2s ago`
- **Regenerate** button inline
- **Provenance line** for legal/financial docs: "Based on: client brief, prior invoice #1042"
- **Watermark** on generated images/PDFs (existing pattern, keep)
- **"Why this output?"** expandable — 1-line plain-English summary of the AI's reasoning (NOT chain of thought, NOT raw prompt).

Forbidden:
- Hiding which model ran.
- Silent regeneration that overwrites previous output.
- AI output that looks identical to user-typed content (always visually distinguishable — left border accent or subtle tint).

## 3. Interruption handling

| Event | Behavior |
|---|---|
| User navigates away mid-generation | Job continues. Toast on completion with "Open output" link. |
| User refreshes page | Resume via `workspace_outputs` if persisted, else show last prompt re-runnable. |
| Network drop | Show inline "Reconnecting…" not a hard error. Auto-retry once. |
| Edge function 8s deadline | Soft message + Retry button. NEVER blank screen. |
| AI provider returns garbage | Show output AND a "This doesn't look right — regenerate" suggestion. |
| Verification denied (403) | `VerificationLock` opens (existing). Never silent failure. |

## 4. Resumability

- `workspace_outputs` already persists every result. UX must:
  - Show last 5 outputs in `/workspace` Overview ("Recent AI outputs").
  - Show project-scoped outputs inside each project detail.
  - Render failed/canceled jobs with a **Resume** button.
- "Continue Working" surface (existing) keeps the last in-flight canvas session.
- ⌘K palette includes "Recent" section — re-run last 10 commands.

## 5. Memory continuity (no new tables)

Implicit memory via existing rows:

- When AI runs INSIDE a project: auto-inject the last 3 `workspace_outputs`
  for that project as context.
- Show the user what's being used: a small chip strip above the prompt input:
  > Using context: `Proposal draft v2` · `Client brief` · `Last invoice`
- User can click any chip to remove it (one-shot opt-out per call).
- No new memory tables. No vector DB. No embedding pipeline. Just
  last-N outputs as context.

## 6. Output quality presentation

Format outputs by type, never as raw markdown blob:

| Output type | Render |
|---|---|
| Proposal / contract | Document preview with download as PDF |
| Invoice line items | Editable table, "Add to invoice" button |
| Email draft | Subject + body fields, "Copy" + "Send via mail client" |
| Roadmap | Timeline component |
| Summary | Card with bullet points |
| Code | Monospace block with copy button |
| Image | Image viewer with watermark |

Never show JSON to the user.

## 7. Command palette as primary AI surface

⌘K is the dominant entry point for execution across the cockpit:

- Type intent → choose target project → run.
- Recently-used commands at top.
- Categories: **Run AI**, **Go to**, **Create**, **Recent**.
- Same palette opens from any workspace route — one muscle memory.
- Esc cancels even if a job is mid-flight (job continues in background).

## 8. Anti-patterns (forbidden)

- ❌ Spinners that never end (deadline guard exists; surface it).
- ❌ Modal dialogs that block the cockpit during AI execution.
- ❌ "Are you sure?" confirmations on regeneration.
- ❌ AI suggestions that interrupt the user's typing flow.
- ❌ "New feature!" tooltips mid-execution.
- ❌ Stacking multiple loading toasts.
- ❌ Errors as raw stack traces or HTTP codes.

## 9. Acceptance signals

This memo's success is measured by:
- Time-to-first-AI-output (signup → first generation) ≤ 90s.
- Zero permanent spinners under any documented failure mode.
- Every AI output is re-openable, regeneratable, and attributable.
- ⌘K is the most-used input surface in the cockpit within 30 days of launch.
- Users describe the product as "an OS", not "a bunch of tools".

## 10. Out of scope (deferred)

- True conversational memory (vector recall) — requires new infra. Not now.
- Multi-step agent chains — requires orchestration UX rethink. Not now.
- Voice input.
- Mobile-first AI surfaces.

This is a UX hardening pass on the runtime we have. No new infra.
